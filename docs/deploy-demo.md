# Deploying the public demo (Render)

The live demo runs on Render's free tier from [`render.yaml`](../render.yaml): the API, the admin
console, a Postgres database and a Redis (Key Value) instance.

**This is not the production path.** Production deploys to Kubernetes via
[`deploy.yml`](../.github/workflows/deploy.yml) and [`infra/k8s`](../infra/k8s), with real SMS,
payment, push and object-storage providers. The demo differs on purpose:

| Setting        | Demo                   | Why                                                               |
| -------------- | ---------------------- | ----------------------------------------------------------------- |
| `NODE_ENV`     | `development`          | Allows the in-process fakes (console SMS, fake payments/push).    |
| `DEMO_MODE`    | `true`                 | Every OTP is `000000`. The env schema refuses this in production. |
| Migrations     | Run on boot            | One instance, so there is no rollout to race.                     |
| Scheduled jobs | Run in the API process | No separate worker on the free tier.                              |
| Photo storage  | Local disk (ephemeral) | Fine for sample data.                                             |

## First deploy

1. Sign in at [render.com](https://render.com) with GitHub.
2. **New → Blueprint**, pick this repository, and click **Apply**. There is nothing to fill in;
   secrets (`JWT_ACCESS_SECRET`, `PAYMENT_WEBHOOK_SECRET`) are generated by Render.
3. Wait for both services to go live (the first Docker build takes ~5 minutes). On its first
   boot the API migrates the database and seeds the catalogue and sample activity
   ([`seed-demo.ts`](../apps/api/scripts/seed-demo.ts)); later boots skip the seed.
4. Open `https://circular-paper-admin.onrender.com` and click **Use demo account**.

If Render gives a service a different URL (the name was taken), update `CORS_ORIGINS` and
`PUBLIC_BASE_URL` on the API and `NEXT_PUBLIC_API_BASE_URL` on the admin in `render.yaml` to match,
then push.

## Things to know

- **Cold starts.** Free services sleep after 15 minutes idle; the next request takes ~30–60 s.
- **Database expiry.** Render's free Postgres expires 30 days after creation. To keep the demo up
  longer, either upgrade it, or create a free database elsewhere (e.g. Neon) and set the API's
  `DATABASE_URL` to its connection string. The API re-seeds an empty database on its next boot.
- **Resetting the data.** Visitors sign in as an admin and can change things. To reset, delete and
  recreate the database (or point `DATABASE_URL` at a fresh one) and restart the API.
- **Deploys.** Render redeploys both services automatically on every push to `main`.

## Building the images locally

```bash
docker build -f infra/render/api.Dockerfile -t cpe-api-demo .
docker build -f infra/render/admin.Dockerfile \
  --build-arg NEXT_PUBLIC_API_BASE_URL=http://localhost:3000/api/v1 -t cpe-admin-demo .
```
